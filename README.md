# 클래스로 마켓 문서 질문 (D22-RAG)

문서를 검색해서 찾은 내용만으로 답하는 작은 RAG 연습 프로젝트예요.
`docs/` 의 문서 6개를 조각내 숫자(임베딩)로 바꿔 두고, 질문과 비슷한 조각 3개를 찾아 AI에게 건네 답을 만들어요.

> `docs/` 의 문서는 수업용 가상 문서예요. 클래스로 마켓은 연습용 가짜 회사이고, 규정과 숫자는 모두 지어낸 것이에요.

## 준비

```bash
pip3 install -r requirements.txt
```

`D22-RAG/.env` 파일을 만들고 아래 세 줄을 채워 주세요. (`.env.example` 을 복사하면 돼요.)

```
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4.1-mini
OPENAI_EMBED_MODEL=text-embedding-3-small
```

- `.env` 는 `.gitignore` 에 들어 있어 깃에 올라가지 않아요. 키를 코드나 채팅에 적지 마세요.
- `OPENAI_MODEL` 은 `temperature=0` 을 지원하는 모델이어야 해요. `gpt-5` 계열은 0을 받지 않아요.

## 실행 순서

| 파일 | 하는 일 |
|---|---|
| `r1_alone.py` | 문서 없이 질문 3개를 그대로 물어봐요. (RAG 없을 때의 답 확인용) |
| `r2_split.py` | 문서를 100 · 400 · 1500자로 잘라 조각 수를 비교해요. |
| `r3_index.py` | 400자(겹침 40자)로 잘라 임베딩하고 `index.json` 으로 저장해요. |
| `r4_search.py "질문"` | 질문과 비슷한 조각 3개를 순위 · 점수 · 파일 이름 · 앞 150글자로 보여 줘요. 검색만 해요. |
| `r5_answer.py "질문"` | 검색 → 프롬프트 만들기 → 모델 호출을 단계별로 보여 주고 답을 만들어요. |
| `app.py` | 위 과정을 웹 화면으로 보여 줘요. |

처음에는 `r3_index.py` 를 먼저 실행해 `index.json` 을 만들어야 r4, r5, app 이 동작해요.

```bash
python3 r3_index.py
python3 r5_answer.py "수업 3일 전에 취소하면 얼마나 돌려받아?"
python3 app.py        # http://127.0.0.1:5001
```

## 웹 화면

- 질문을 입력하고 **물어보기** 를 누르면 답과 찾아온 조각(파일 이름 · 점수 · 앞 150글자)이 나와요.
- 질문이 300자를 넘으면 안내 문장과 함께 입력 화면으로 돌아와요.
- `index.json` 은 앱이 켜질 때 한 번만 읽어요.
- 내 컴퓨터(127.0.0.1)에서만 접속돼요. 개발용 서버라 외부에 공개하지 마세요.

## 구조

```
D22-RAG/
├─ docs/            검색 대상 문서 (.md)
├─ templates/
│  └─ ask.html      웹 화면
├─ rag.py           공통 함수 (읽기 · 자르기 · 임베딩 · 검색 · 프롬프트 · 답 · 출처 검사)
├─ r1_alone.py ~ r5_answer.py
├─ app.py           Flask 앱
├─ index.json       r3 이 만드는 인덱스 (깃에 올리지 않음)
├─ requirements.txt
└─ .env             API 키와 모델 이름 (깃에 올리지 않음)
```

## 동작 방식

1. **자르기:** `RecursiveCharacterTextSplitter` 로 400자(겹침 40자) 조각을 만들고, 조각마다 파일 이름을 출처로 붙여요.
2. **임베딩:** 조각을 숫자로 바꿔 `index.json` 에 저장해요.
3. **검색:** 질문도 숫자로 바꿔 코사인 유사도로 비교해요. **점수가 클수록 비슷해요.** 점수는 보통 0.4~0.7 범위라서, 같은 질문 안에서 순위를 비교하는 용도예요.
4. **답 만들기:** 찾아온 조각 3개를 프롬프트의 `[자료]` 칸에 넣고, 자료 안의 내용만으로 답하게 해요. 자료에 없으면 `문서에서 찾지 못했어요` 만 답해요.
5. **출처 검사:** 답 마지막 줄의 `출처: 파일이름` 이 찾아온 조각의 파일 이름인지 코드가 확인해요. 틀리면 점수가 가장 높은 조각의 파일로 바꾸고 경고를 보여 줘요.

질문 하나에 OpenAI 호출은 2번이에요. 임베딩 1번, 답 만들기 1번이에요.

## 알아 둘 점

- 출처 검사는 파일 이름이 찾아온 조각 안에 있는지만 봐요. 답에 쓰지 않은 파일을 적어도 통과해요.
- 검색은 앞 3개 조각만 쓰기 때문에, 질문이 넓으면 일부 규정이 답에서 빠질 수 있어요.
- 문서를 바꾸면 `python3 r3_index.py` 를 다시 실행해 `index.json` 을 새로 만들어야 해요.
- `.env` 의 `OPENAI_EMBED_MODEL` 을 바꿨을 때도 `r3_index.py` 를 다시 실행해야 해요. 모델이 다르면 점수가 의미가 없어요.
