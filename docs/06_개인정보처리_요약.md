# 클래스로 마켓 · 개인정보 처리방침 요약

> ※ 수업용 가상 문서예요. 클래스로 마켓은 연습용 가짜 회사이고, 실제 개인정보 처리방침이 아니에요.
> 시행일: 2026년 10월 1일

## 1. 어떤 정보를 모으나요?
| 언제 | 모으는 정보 |
|---|---|
| 회원 가입 | 이름 · 이메일 · 휴대폰 번호 · 생년월일(생일 쿠폰용, 선택) |
| 결제 | 결제 수단 정보 (카드 번호 전체는 저장하지 않고 결제 대행사가 처리해요) |
| 리뷰 작성 | 리뷰 내용 · 사진 · 작성자 성(공개 시 이름은 ** 로 가림) |
| 강사 등록 | 이름 · 연락처 · 정산 계좌 · 작품 사진 · (운동 분야) 자격증 사본 |

## 2. 얼마나 보관하나요?
- 회원 정보: 탈퇴할 때까지. 탈퇴하면 **5일 안에** 지워요.
- 결제 기록: 법에 따라 **5년** 보관해요.
- 1년 동안 로그인하지 않은 계정은 따로 분리해 보관하고, 분리 30일 전에 이메일로 알려 드려요.

## 3. 다른 곳에 주나요?
- 수강 신청한 클래스의 강사에게 **수강생 이름(성 + 이름 첫 글자)과 신청 인원**만 알려요. 휴대폰 번호 · 이메일은 강사에게 주지 않아요.
- 그 밖에는 본인이 동의했거나 법에 정해진 경우에만 다른 곳에 줘요.

## 4. 내 정보 보기 · 고치기 · 지우기
- 마이페이지(로그인 필요)에서 언제든 내 정보를 보고 고칠 수 있어요.
- 탈퇴는 마이페이지 → 설정 → 회원 탈퇴에서 할 수 있어요.

## 5. 개인정보 보호 담당
- 개인정보 관련 문의는 고객센터 채팅 상담에서 '개인정보' 메뉴를 골라 남겨 주세요.
